# Edge bring-up — Secrets Manager Edge on the same Docker host as Jenkins

This is the demo path where the Jenkins Conjur plugin authenticates against a **local Conjur Cloud Edge** container instead of reaching out to the Conjur Cloud SaaS endpoint. The Edge replicates policy + secrets from the SaaS over an outbound-only TLS connection, then validates JWTs and serves secrets locally.

```text
laptop / Docker
┌────────────────────────────────────────────────────────────────┐
│  Jenkins ──JWT──> Conjur Edge ──jwks-uri──> Jenkins JWKS       │
│  (cybr-jenkins)   (cybr-conjur-edge)         (host:8081)       │
│                          ↑                                     │
│                          └──outbound TLS──> Conjur Cloud SaaS  │
└────────────────────────────────────────────────────────────────┘
```

No public hostname for Jenkins is required — Edge resolves Jenkins via Docker Desktop's `host.docker.internal`.

## Prereqs

- `setup/vars.env` in this demo is populated (see `setup/vars.env.example`).
- The base demo (`bash go.sh`) has run successfully at least once with the default `cloud` target — `cybr-jenkins` exists and the Conjur Cloud authenticator policy is loaded.
- You have **Edges** entitlement on your Conjur Cloud tenant.

## One-time prep — load the Edge image

CyberArk distributes the Edge container as a Marketplace tarball (no registry pull):

1. Download from the [CyberArk Marketplace](https://community.cyberark.com/marketplace/s/#software-aK4Vy000000004rKAA-): `conjur-edge_<version>.tar.gz`.
2. Load it:

   ```bash
   sudo docker load -i ~/Downloads/conjur-edge_*.tar.gz
   ```

3. Verify:

   ```bash
   sudo docker images | grep edge
   # localhost/cyberark/edge   1.x.x   ...
   ```

## Per-Edge prep — generate the install script in the SaaS UI

1. Sign into Secrets Manager UI -> **Edges** -> **Install new Edge**.
2. Fill in:
   | Field | Value |
   |-------|-------|
   | Container platform | Docker |
   | Edge name | anything (the SaaS-side label) |
   | Edge container name | `cybr_conjur_edge` — **underscores only**, the SaaS UI rejects hyphens. Must match `EDGE_CONTAINER` in `setup/vars.env`. |
   | Persistence folder | `/Users/<you>/cyberark` on macOS, `/home/cyberark` on Linux |
   | TLS certificate | Auto-generated by Edge |
   | `COMMON_NAME` | `host.docker.internal` |
   | `SAN` | `127.0.0.1,localhost` |
3. Click **Create Edge and generate script**.
4. Copy the **entire** generated `docker run` block.
5. Save it as `setup/edge/install.sh` in this directory. (Gitignored — contains a one-shot install token.)
6. **macOS only:** edit the saved file to replace any literal `/cyberark` with `"$HOME/cyberark"` (the root of `/` is read-only on macOS).

> **The install token expires 8 minutes after generation.** If you don't run `bash setup.sh` within that window, regenerate the script in the SaaS UI and re-save.

## Bring Edge up

```bash
bash setup/edge/setup.sh
```

What this does:

1. Verifies the `localhost/cyberark/edge:*` image is loaded.
2. Creates `$HOME/cyberark` (macOS) or `/cyberark` (Linux) and `chown`s it to uid 5000.
3. Removes any prior `cybr-conjur-edge` container.
4. Runs `setup/edge/install.sh` (the SaaS-generated `docker run`).
5. Waits for the container to be running and `/health` to respond (up to ~5 min for first replication).
6. Calls `import_edge_cert.sh` to extract the Edge self-signed cert and import it into the `cybr-jenkins` Java truststore. Restarts Jenkins.

## Switch the demo to Edge mode

Edit `setup/vars.env`:

```bash
JWT_TRUST_MODE="jwks-uri"
CONJUR_AUTH_TARGET="edge"
```

Then re-bind:

```bash
bash configure_jenkins.sh   # updates plugin appliance URL to https://host.docker.internal/api
bash finish_setup.sh        # switches Conjur authenticator from public-keys to jwks-uri,
                            # sets jwks-uri to http://host.docker.internal:8081/...,
                            # re-creates Jenkins ConjurSecretCredentialsImpl entries,
                            # triggers a sanity build
```

The sanity build at the end verifies end-to-end: Jenkins -> Edge -> JWKS check -> secret retrieval.

## Tear down

```bash
bash setup/edge/remove.sh
```

This stops the Edge container. To fully clean up, also delete the Edge instance in the SaaS UI (Edges page -> ... -> Delete).

To return to the default cloud + public-keys demo path:

```bash
# in setup/vars.env
JWT_TRUST_MODE="public-keys"
CONJUR_AUTH_TARGET="cloud"

bash configure_jenkins.sh
bash finish_setup.sh
```

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| `setup.sh` fails: image not loaded | Marketplace tarball never `docker load`'d | `sudo docker load -i conjur-edge_*.tar.gz` |
| Marketplace tarball is `secrets-manager-edge-1.7.0.tar.gz` but SaaS UI installs `localhost/cyberark/edge:1.8.0` | Image version drift between Marketplace download and SaaS-generated install script | After `docker load`, also tag: `docker tag localhost/cyberark/edge:1.7.0 localhost/cyberark/edge:1.8.0` |
| Edge container exits with `401 Unauthorized` | `EDGE_INITIAL_CREDS` token expired (8-min window) | Regenerate install script in SaaS UI, re-save, re-run |
| Edge container restart-loops with `panic: mkdir /opt/edge/data/logs: permission denied` | Docker Desktop bind-mount uid mapping failed | The container panics *before* hitting Conjur Cloud, so the install token may still be valid. Stop container, `sudo chmod -R 777 "$HOME/cyberark"`, `docker start cybr_conjur_edge`. `setup.sh` now applies chmod 777 proactively. |
| `/health` never responds | Initial replication failed; check `docker logs cybr_conjur_edge` for outbound network issues | Verify host can reach Conjur Cloud SaaS |
| Jenkins build fails: `unable to find valid certification path` | Edge cert not in Jenkins truststore | `bash setup/edge/import_edge_cert.sh` |
| `finish_setup.sh` warns `Authenticator status: HTTP 500 ... CONJ00087E ... invalid URI` | SaaS Conjur cannot resolve `host.docker.internal` (it's a Docker-network-only hostname) | Cosmetic — Edge does the validation, not SaaS. The sanity build at the end of `finish_setup.sh` is the real verification. As of this version, the script skips this check in Edge mode. |
| Jenkins build fails: `Authentication failed. Cannot get token from Conjur` | Edge can't fetch JWKS at the URL Conjur policy says | Verify `JWKS_URL_OVERRIDE` resolves from inside the Edge container; default `host.docker.internal` works on Docker Desktop |
